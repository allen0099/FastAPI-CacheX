::: fastapi_cachex.exceptions

`fastapi_cachex.exceptions.CacheError` is deprecated since 0.3.8 and not listed
above. Nothing in the package raises it, and accessing it emits a
`DeprecationWarning`. Catch `CacheXError` instead. It will be removed in 0.4.0.
