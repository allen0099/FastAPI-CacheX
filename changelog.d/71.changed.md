**`BaseCacheBackend.delete()` returns whether a key was removed.** The memory,
Redis and Memcached backends return `True` when the key held an entry and
`False` otherwise; on memory an entry that had already expired counts as
absent, as it does on Redis. The base `delete_many()` fallback now counts only
the keys that existed, and the non-atomic `get_and_delete()` and
`delete_if_equals()` fallbacks use the result, so a caller whose delete found
the key already gone no longer wins as well. A third-party backend that declares `-> None` fails type
checking and should return the result instead. See the
[migration guide](https://fastapi-cachex.readthedocs.io/en/stable/MIGRATING_0_4/#backend-delete).
