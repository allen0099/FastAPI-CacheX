**The remaining warnings log the exception message and the path with `%r`.**
The stale-refresh and serve-stale warnings of `@cache`, its distributed-lock
wait warning, its miss-lock release warning and `get_or_set()`'s "Refreshing a
stale value failed" no longer write them verbatim, so a CR/LF or an ANSI escape
in a handler's or factory's error message cannot forge or colour a log line.
