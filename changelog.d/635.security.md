**`@cache` and `get_or_set()` warnings log error messages and request paths
with `%r`.** The stale-refresh, serve-stale, distributed-lock wait and miss-lock
release warnings of `@cache`, and `get_or_set()`'s "Refreshing a stale value
failed", wrote them verbatim, so a CR/LF or an ANSI escape in a handler's,
factory's or backend's error message, or an ANSI escape in the path, could forge
or colour a log line. The backend-failure warnings have done so since 0.7.1.
