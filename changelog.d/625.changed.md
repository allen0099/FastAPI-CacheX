**Three common mistakes get an error that says what to do.**
`BackendProxy.set()` and `CacheManagerProxy.set()` raise `TypeError` for
anything but an instance of their type or `None`, so passing the class
(`BackendProxy.set(MemoryBackend)`) or a name fails at once instead of making
every later request fail open. `invalidate()` given a path string raises
`TypeError` pointing to `invalidate_path()`, instead of an `AttributeError`. A
`key_builder` that cannot take the request names its signature instead of
quoting `inspect`'s "too many positional arguments".
A test that registers a bare `AsyncMock()` or `MagicMock()` as the backend or
manager now fails too; build it with `spec=` (`MagicMock(spec=CacheManager)`).
