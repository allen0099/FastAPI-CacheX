**`@cached` no longer gives calls that differ only in a secret one key.**
pydantic writes a `SecretStr` or `SecretBytes` as `"**********"`, so
`load(Creds(token=SecretStr("a")))` and the same call with token `"b"` shared
an entry, and in a multi-tenant app one tenant could get another's result. An
argument that holds a secret, at any depth, now raises `CacheXError` and asks
for `key=`.
