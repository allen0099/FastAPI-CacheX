**`@cache` no longer special-cases the removed session middleware or
`X-Session-Token`.** A request bypasses the shared backend for an
`Authorization` header or a non-empty `request.session` from any session
middleware, as before; a session that `FastAPICacheXSessionMiddleware` loaded
no longer counts, since the middleware is gone. `X-Session-Token` in
`@cache(vary=[...])` is keyed on its value like any other header instead of on
its SHA-256 digest. A `Cookie` header alone still does not bypass the cache.
See [Migrating to 0.5.0](https://fastapi-cachex.readthedocs.io/en/latest/MIGRATING_0_5/#cache-session-token).
