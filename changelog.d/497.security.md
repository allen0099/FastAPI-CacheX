**`CacheLock` no longer writes the lock key to the log at `WARNING`.** When an
interrupted `acquire()` could not withdraw its claim, the warning held the full
key, which often embeds a user ID or an e-mail address. It now carries a digest
(`key_ref`), with the full key at `DEBUG` under the same digest, as the
`@cache` and `CacheManager` warnings already did.
