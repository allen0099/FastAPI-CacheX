**`@cached` refuses an argument whose model holds an iterator, instead of
using it up.** pydantic validates an `Iterable` field into a lazy iterator.
Building the default key read it, so the function then ran on an empty
iterable and that result was cached, and a secret inside it was keyed as its
mask. Such an argument, at any depth, now raises `CacheXError` and asks for
`key=`, the same as an iterator passed directly, and is left unread.
