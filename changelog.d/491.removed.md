**Python 3.10 is no longer supported.** 0.6.0 requires Python 3.11 or later;
Python 3.10 reached its end of life in October 2026, and 0.5.2 and 0.5.3
warned about this at import time. `pip` and `uv` keep installing 0.5.3 on
Python 3.10. See
[Migrating to 0.6.0](https://fastapi-cachex.readthedocs.io/en/stable/MIGRATING_0_6/#python-311).
