**A value read from Redis or Memcached costs at most 16 MiB to decompress, and an
overlong counter reads as a value instead of raising.** A compressed value was
inflated up to 256 MiB on the event loop, so a value of a few hundred KiB
written by anyone with access to the cache server cost that much memory on every
read; documents over 16 MiB are now stored uncompressed, and a compressed value
that would inflate past that is a miss. A stored counter of more than 4300
digits made `CacheManager.get()` raise `ValueError`; a counter now has at most
20 digits, as a 64-bit one does, and anything longer is read as an ordinary
value, which is a miss.
